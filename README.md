Application Name : Cure Audio VST

Problem: A producer or musician needs a tool to generate sounds for a song or audio project.

User: Music Producers/Musicians

Main Features: Dropdown menu to browse categories, two possible UI screens depending on user choice(Wavetable Generator or Live instrument/Sampler), A box for wavetable or sample with adjustable knobs for parameters, a box for an ADSR Envelope that affects the sounds volume and timing, a box for a filter that filters what frequencies are coming through,and an FX rack with slots to add desired effects to the sound before its routed to the audio bus and out of the program.

Explanation: The user will open the VST and be prompted to choose from the dropdown menu (Browse Categories). If they choose wavetable the Wavetable UI will open for use. If they choose live instrument/Sampler another sub-menu will branch out and theyll choose from multiple categories and finally pick what sample or instrument recording they want to load for use. The user will then use keys on thier computer keyboard or a plugged in MIDI instrument to press notes and generate sound, they have the ablity to adjust parameters and add fx before doing so. The audio then will be routed to the audio bus and out the main DAW the project is being created in.
